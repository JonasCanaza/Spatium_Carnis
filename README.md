# Spatium Carnis

**Spatium Carnis** is an *arcade shooter*-style game inspired by the classic **Asteroids**, featuring an aesthetic and atmosphere influenced by **Vita Carnis**.  

---

## 🧠 Description

In **Spatium Carnis**, you control a spaceship trapped in a strange, organic universe.  
Your goal is to **survive** as hordes of specimens and fungi begin to appear.

The game combines:
- Classic arcade dynamics.
- Immersive sound design.
- A raw, unsettling visual style inspired by *Vita Carnis*.

---

## Features

- Full 360° movement control.  
- Dynamically generated enemies.  
- Integrated music and sound effects system.  
- Minimalist and fluid interface.  
- Direct inspiration from the *Vita Carnis* aesthetic.
